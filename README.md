# Byte-Level BPE Tokenizer

A **Byte Pair Encoding (BPE) tokenizer implemented from scratch in Python**, with benchmarking against production tokenizer implementations from **OpenAI `tiktoken`** and **Hugging Face**.

The project explores the tokenization layer used in modern Large Language Model pipelines, from raw UTF-8 bytes through learned BPE merge rules and token IDs.

## Overview

LLMs do not process raw text directly. Text first passes through a tokenizer:

```text
Raw Text
   ↓
Unicode / UTF-8
   ↓
Bytes
   ↓
Byte Pair Encoding
   ↓
Token IDs
   ↓
Transformer / LLM
```

This project implements the core **byte-level BPE algorithm from scratch** and provides a common environment for comparing it with optimized tokenizer libraries.

## Features

## BPE Implementation

The tokenizer begins with the **256 possible byte values** as its initial vocabulary.

During training, it repeatedly:

1. Counts adjacent token pairs.
2. Finds the most frequently occurring pair.
3. Assigns the pair a new token ID.
4. Replaces occurrences of that pair.
5. Stores the learned merge rule.
6. Repeats until the requested vocabulary size is reached.

For example:

```text
A A B A A B
```

If `(A, A)` is the most frequent pair:

```text
(A, A) → Token 256
```

The sequence becomes:

```text
256 B 256 B
```

These learned merge rules are then applied when encoding new text.

## Using the Custom BPE Tokenizer

```python
from Tokenizers import BPE

training_text = """
Large language models process text as sequences of tokens.
Tokenization converts raw text into numerical representations.
"""

tokenizer = BPE(training_text)

# Train a vocabulary of 300 tokens
tokenizer.train(vocab_size=300)

text = "Hello world!"

tokens = tokenizer.encode(text)
decoded = tokenizer.decode(tokens)

print("Tokens:", tokens)
print("Decoded:", decoded)
```

Verify lossless encoding and decoding:

```python
assert tokenizer.decode(tokenizer.encode(text)) == text
```

Because the tokenizer operates on UTF-8 bytes, it can also represent multilingual and Unicode text:

```python
text = "Hello 👋🌎 你好世界 مرحبا بالعالم"

tokens = tokenizer.encode(text)
decoded = tokenizer.decode(tokens)
```

## Benchmarking

The project includes a benchmarking framework comparing:

* **Custom BPE** — Python implementation from this repository
* **OpenAI `tiktoken`** — `o200k_base`
* **Hugging Face Tokenizers** — GPT-2 tokenizer

The benchmark evaluates:

| Metric                 | Description                                       |
| ---------------------- | ------------------------------------------------- |
| Token Count            | Number of tokens generated                        |
| Bytes / Token          | Tokenization compression efficiency               |
| Average Time           | Mean runtime across benchmark runs                |
| Median Time            | Median runtime                                    |
| Standard Deviation     | Runtime variability                               |
| Throughput             | MB processed per second                           |
| Round-Trip Correctness | Whether decode(encode(text)) reproduces the input |

Each tokenizer is warmed up before measurement and evaluated across multiple runs.

### Run the benchmark

From the project root:

```bash
python -m benchmarks.benchmark_tokenizers
```

The benchmark prints the results to the terminal and saves them to:

```text
results/benchmark_results.csv
```

Example output:

```text

============================================================

```

The benchmark is intended to compare both **tokenization behavior** and **implementation performance**. The custom implementation prioritizes transparency and understanding of the BPE algorithm, while libraries such as `tiktoken` and Hugging Face use highly optimized production implementations.
